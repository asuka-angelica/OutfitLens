# Outfit Lens

ゲーム内スクリーンショットに、装備している衣装の「部位名・衣装名・アイコン」をまとめた衣装カードを追加して、1枚のPNG画像として保存するWindowsアプリです。

画像処理はすべてPC内で完結します。画像のアップロード、テレメトリー、広告、ネットワーク送信はありません。

「ブループロトコル：スターレゾナンス」を題材とした非公式・非営利の二次創作ツールです。ゲームの運営・開発各社による公式ツール、認可製品、後援企画ではありません。

## 概要

Outfit Lensは、ゲーム内で作ったコーディネートを「スクリーンショットだけでなく、使用した衣装名と一緒に残したい」という用途のためのデスクトップアプリです。

ユーザーが次の2種類の画像をアプリへ渡します。

1. 完成画像の背景になる通常のゲームスクリーンショット
2. 装備内容を確認するための、各部位を開いた衣装部屋スクリーンショット

アプリは衣装部屋画面の左上に表示された `衣装部屋/トップス` などの文字と、左側の選択枠位置を使って部位を判定します。追加された部位・衣装名・アイコンを衣装カードとして整理し、ゲーム内スクリーンショットへ合成した新しいPNG画像を作成します。

衣装カードは、ゲーム内スクリーンショットへ重ねるだけでなく、画像の右側または下側へ専用フレームとして追加できます。そのため、キャラクターや背景を隠さずにコーディネート情報を掲載できます。縦長・横長画像の両方に対応し、アイコンを表示しない文字のみの出力も選べます。

部位名はWindows内蔵OCRと画面上の選択位置から自動判定し、画面右側に表示された衣装名もOCRで読み取ります。衣装名や認識結果は保存前にユーザーが確認・編集できるため、読み取りに失敗した場合もそのまま作業を続けられます。

長い衣装名がゲーム画面上で複数行に折り返されている場合は、OCR結果を表示順に連結して1つの衣装名へ復元します。改行位置で部位名の末尾が欠けた場合も、認識済みの部位名と照合して補完します。

`ハッピー・Tシャツ` のように衣装名の末尾へ部位名が付かない表示形式にも対応しています。

すべての処理はWindows PC内で完結します。ゲーム画像を外部サービスやAI APIへ送信せず、アカウント登録も必要ありません。

想定している用途：

- お気に入りのコーディネート記録
- SNSへ投稿する衣装紹介画像の作成
- フレンドへ衣装の組み合わせを共有
- 過去の衣装構成を後から確認するための保存

## できること

- ゲーム内スクリーンショットへ衣装一覧を合成
- 衣装カードを画像の右側／下側へ追加して、キャラクターに重ならない画像を作成
- 画像内の左上／右上／左下／右下への配置
- 縦長・横長スクリーンショット対応
- 衣装アイコンの表示／非表示
- 衣装部屋画像の複数ファイル選択
- クリップボードからの貼り付けと `Ctrl+V`
- Windows内蔵OCRによる部位名・衣装名のオフライン認識
- 認識した部位名と衣装名の手動修正
- PNG形式で保存

## 動作環境

- Windows 10 / 11（64-bit）
- .NET 10 Desktop Runtime
- 日本語OCRが利用できるWindows環境を推奨

OCRが利用できない場合も、衣装部屋画面の選択枠位置から部位を判定します。判定結果は保存前に手動で修正できます。

## ダウンロードと起動

1. このリポジトリの [Releases](https://github.com/asuka-angelica/OutfitLens/releases/latest) を開きます。
2. 最新版の `OutfitLens-Windows.zip` をダウンロードします。
3. ZIPを右クリックして「すべて展開」を選びます。
4. 展開したフォルダー内の `OutfitLens.exe` を起動します。
5. .NET Desktop Runtimeを求められた場合は、Microsoft公式の案内に従って .NET 10 Desktop Runtimeをインストールします。

ZIP内から直接起動せず、必ず先に展開してください。公式配布元は、このリポジトリのGitHub Releasesのみです。

## 用意する画像

### 1. ゲーム内スクリーンショット

衣装カードを付けたい、ゲーム内で撮影した通常のスクリーンショットです。

- 縦長・横長のどちらでも使用できます。
- キャラクターが中央や左右にいても使用できます。
- 衣装カードの配置は後から選択できます。

### 2. 衣装部屋スクリーンショット

衣装の部位とアイコンを読み取るための画像です。ゲームの衣装部屋を開き、対象部位を選択した状態で撮影します。

使用できる画面の例：

- `衣装部屋/セット`
- `衣装部屋/トップス`
- `衣装部屋/ボトムス`
- `衣装部屋/ガントレット`
- `衣装部屋/靴`
- `衣装部屋/頭飾り`
- `衣装部屋/髪飾り`
- `衣装部屋/顔飾り`
- `衣装部屋/唇飾り`
- `衣装部屋/背飾り`
- `衣装部屋/尻尾飾り`
- `衣装部屋/耳飾り`
- `衣装部屋/首飾り`
- `衣装部屋/指輪`

撮影時は次の状態を確認してください。

1. 画面左上に `衣装部屋/トップス` などの部位名が表示されている。
2. 左側の部位一覧で、装備中のアイコンが選択枠で囲まれている。
3. 右側で装備中の衣装が選択され、衣装名が表示されている。
4. メニューや別ウィンドウが衣装部屋画面へ重なっていない。

部位ごとに1枚ずつ用意します。すべての部位を用意する必要はなく、最終画像へ載せたい部位だけで構いません。

### 頭飾りが2枠ある場合

頭飾りの第1枠と第2枠は、別々のスクリーンショットとして追加してください。

- 第1枠は `頭飾り`
- 第2枠は `頭飾り2`

として個別に一覧へ追加されます。第2枠を選択した状態で撮影することが重要です。

## 基本的な使い方

### 手順1：ゲーム内スクリーンショットを選ぶ

1. アプリを起動します。
2. 「ゲーム内スクリーンショットを選択」を押します。
3. 「ピクチャー」内の `StarASIA` フォルダーから、衣装カードを付けたい画像を選びます。
4. 左側のプレビューへ画像が表示されたことを確認します。

### 手順2：衣装部屋スクリーンショットを追加する

追加方法は2種類あります。

#### ファイルから追加

1. 「ファイルから追加」を押します。
2. 用意した衣装部屋スクリーンショットを選びます。
3. 複数の部位を一度に選択することもできます。

#### クリップボードから追加

> **衣装部屋スクリーンショットをクリップボードから追加する場合は、PCで撮影したスクリーンショット画像を使用することを前提としています。**  
> 衣装部屋を表示しているゲームウィンドウをアクティブにし、`Alt + Print Screen` などで画面をクリップボードへコピーしてください。キーボードによっては `Fn` キーとの同時押しが必要です。

1. ゲームまたは画像ビューアーで衣装部屋の画像をクリップボードへコピーします。
2. Outfit Lensへ戻ります。
3. 「クリップボードから追加」を押すか、`Ctrl+V` を押します。
4. 部位を変えて撮影・コピーし、必要な数だけ繰り返します。

ファイル名、ファイルパス、画像URL、画像が掲載されたWebページのコピーでは追加できません。クリップボードに画像そのものが入っている必要があります。

追加した部位は画面右側の一覧へ表示されます。同じ部位をもう一度追加すると、その部位の内容が新しい画像で置き換わります。`頭飾り` と `頭飾り2` は別部位として保持されます。

### 手順3：認識結果を確認・修正する

各行には、衣装アイコン、部位名、衣装名、削除ボタンが表示されます。

- 部位名が違う場合：部位のプルダウンから正しい項目を選びます。
- 衣装名が違う、または「名称を確認してください」と表示された場合：衣装名欄をクリックして正しい名前を入力します。
- 不要な行がある場合：右端の `×` を押します。

部位名は自動認識されますが、衣装名を含め、必ず保存前に表示内容を確認してください。

### 手順4：衣装カードの配置を選ぶ

「衣装カードの配置」から選びます。

- **右側の専用フレーム**：ゲーム内スクリーンショットの右へ衣装カードを追加します。キャラクターや背景へ重なりません。
- **下側の専用フレーム**：ゲーム内スクリーンショットの下へ衣装カードを追加します。横長画像に向いています。
- **画像内・左上／右上／左下／右下**：ゲーム内スクリーンショットの中へ衣装カードを重ねます。

画像内配置でキャラクターと重なる場合は、右側または下側の専用フレームを選んでください。

### 手順5：アイコン表示を選ぶ

「衣装アイコンを表示する」のチェックで切り替えます。

- チェックあり：部位名・衣装名・切り抜いたアイコンを表示
- チェックなし：部位名と衣装名だけを表示

アイコンなしモードでも部位認識と衣装名編集は利用できます。

### 手順6：プレビューを確認して保存する

1. 「プレビュー更新」を押します。
2. 配置、文字、衣装名、アイコンを確認します。
3. 「PNGとして保存」を押します。
4. 保存先とファイル名を指定します。

元のスクリーンショットは変更されません。結果は新しいPNGファイルとして保存されます。

## うまく認識されない場合

### 部位が違う

- 衣装部屋画面の左上に部位名が表示されているか確認してください。
- 対象部位が左側の選択枠で囲まれているか確認してください。
- 画面全体を切り抜かず、そのまま追加してください。
- 一覧の部位プルダウンから手動で修正できます。

### 衣装名を取得できない

衣装名欄へ「名称を確認してください」と表示された場合や、異なる名前が表示された場合は、衣装部屋画面右側の名称を確認して手動入力してください。

### アイコンが違う

- 装備中の部位が左側で選択されているか確認してください。
- 頭飾りは第1枠と第2枠のどちらを選択しているか確認してください。
- 正しい状態の衣装部屋画像を追加し直してください。

### `Ctrl+V`で追加できない

- クリップボードへ画像そのものがコピーされているか確認してください。
- ファイル名やファイルパスのコピーでは追加できません。
- 「クリップボードから追加」ボタンでも試してください。

### アプリが起動しない

- ZIPを展開してから起動してください。
- .NET 10 Desktop Runtimeがインストールされているか確認してください。
- Windowsの「プロパティ」に「許可する」または「ブロックの解除」が表示される場合は、内容を確認して有効にしてください。

## 対応画像

- PNG
- JPG / JPEG
- WebP

衣装部屋のUI配置は、1920×1080相当の比率を基準に認識し、異なる解像度には比率補正を行います。UIレイアウトが大きく異なる画像では手動修正が必要になる場合があります。

> **衣装部屋スクリーンショットをクリップボードから追加する場合は、PCで撮影したスクリーンショット画像を使用することを前提としています。**  
> 衣装部屋を表示しているゲームウィンドウをアクティブにし、`Alt + Print Screen` などで画面をクリップボードへコピーしてください。キーボードによっては `Fn` キーとの同時押しが必要です。

1. ゲームまたは画像ビューアーで衣装部屋の画像をクリップボードへコピーします。
2. Outfit Lensへ戻ります。
3. 「クリップボードから追加」を押すか、`Ctrl+V` を押します。
4. 部位を変えて撮影・コピーし、必要な数だけ繰り返します。

ファイル名、ファイルパス、画像URL、画像が掲載されたWebページのコピーでは追加できません。クリップボードに画像そのものが入っている必要があります。

追加した部位は画面右側の一覧へ表示されます。同じ部位をもう一度追加すると、その部位の内容が新しい画像で置き換わります。`頭飾り` と `頭飾り2` は別部位として保持されます。

### 手順3：認識結果を確認・修正する

各行には、衣装アイコン、部位名、衣装名、削除ボタンが表示されます。

- 部位名が違う場合：部位のプルダウンから正しい項目を選びます。
- 衣装名が違う、または「名称を確認してください」と表示された場合：衣装名欄をクリックして正しい名前を入力します。
- 不要な行がある場合：右端の `×` を押します。

部位名は自動認識されますが、衣装名を含め、必ず保存前に表示内容を確認してください。

### 手順4：衣装カードの配置を選ぶ

「衣装カードの配置」から選びます。

- **右側の専用フレーム**：元画像の右へ衣装カードを追加します。キャラクターや背景へ重なりません。
- **下側の専用フレーム**：元画像の下へ衣装カードを追加します。横長画像に向いています。
- **画像内・左上／右上／左下／右下**：元画像の中へ衣装カードを重ねます。

画像内配置でキャラクターと重なる場合は、右側または下側の専用フレームを選んでください。

### 手順5：アイコン表示を選ぶ

「衣装アイコンを表示する」のチェックで切り替えます。

- チェックあり：部位名・衣装名・切り抜いたアイコンを表示
- チェックなし：部位名と衣装名だけを表示

アイコンなしモードでも部位認識と衣装名編集は利用できます。

### 手順6：プレビューを確認して保存する

1. 「プレビュー更新」を押します。
2. 配置、文字、衣装名、アイコンを確認します。
3. 「PNGとして保存」を押します。
4. 保存先とファイル名を指定します。

元のスクリーンショットは変更されません。結果は新しいPNGファイルとして保存されます。

## うまく認識されない場合

### 部位が違う

- 衣装部屋画面の左上に部位名が表示されているか確認してください。
- 対象部位が左側の選択枠で囲まれているか確認してください。
- 画面全体を切り抜かず、そのまま追加してください。
- 一覧の部位プルダウンから手動で修正できます。

### 衣装名を取得できない

衣装名欄へ「名称を確認してください」と表示された場合や、異なる名前が表示された場合は、衣装部屋画面右側の名称を確認して手動入力してください。

### アイコンが違う

- 装備中の部位が左側で選択されているか確認してください。
- 頭飾りは第1枠と第2枠のどちらを選択しているか確認してください。
- 正しい状態の衣装部屋画像を追加し直してください。

### `Ctrl+V`で追加できない

- クリップボードへ画像そのものがコピーされているか確認してください。
- ファイル名やファイルパスのコピーでは追加できません。
- 「クリップボードから追加」ボタンでも試してください。

### アプリが起動しない

- ZIPを展開してから起動してください。
- .NET 10 Desktop Runtimeがインストールされているか確認してください。
- Windowsの「プロパティ」に「許可する」または「ブロックの解除」が表示される場合は、内容を確認して有効にしてください。

## 対応画像

- PNG
- JPG / JPEG
- WebP

衣装部屋のUI配置は、1920×1080相当の比率を基準に認識し、異なる解像度には比率補正を行います。UIレイアウトが大きく異なる画像では手動修正が必要になる場合があります。

## プライバシーと安全性

- 完全オフラインで動作
- 画像アップロードなし
- テレメトリーなし
- 広告なし
- 外部APIなし
- ゲーム画像やゲーム由来の画像テンプレートをソースコード・配布物へ同梱していません

ユーザーが選択した画像は、衣装カードの作成以外には使用されません。
