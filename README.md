# Outfit Lens

ゲームの通常スクリーンショットと衣装部屋のスクリーンショットから、装備中の部位・衣装名・アイコンをまとめた画像を作成するWindowsアプリです。

画像処理はすべてPC内で完結します。画像のアップロードやネットワーク送信は行いません。

「ブループロトコル：スターレゾナンス」を題材とした非公式・非営利の二次創作ツールです。ゲームの運営・開発各社による公式ツール、認可製品、後援企画ではありません。

## 主な機能

- 通常スクリーンショットへ衣装一覧を合成
- 画像に重ならない右側／下側の専用フレーム
- 縦長・横長スクリーンショット対応
- アイコン表示／アイコンなしモード
- クリップボード貼り付けと `Ctrl+V`
- Windows内蔵OCRによる完全オフラインの部位認識
- 認識結果の候補選択と手動修正
- PNG出力

## ダウンロード

このリポジトリの **Releases** から最新の `OutfitLens-Windows.zip` をダウンロードし、展開後に `OutfitLens.exe` を起動してください。公式配布元はこのGitHub Releasesのみです。他サイトへの転載・再配布・ミラーは許可していません。

> 実行には .NET 10 Desktop Runtime が必要です。

## プライバシーと安全性

オフライン専用です。テレメトリー、広告、画像アップロードはありません。ゲーム画像やゲーム由来の画像テンプレートは、ソースコードおよび配布物に同梱していません。
